This is a program made specifically for ExplorerEx, although it should work on any Windows build with Balloon Notifications.

It gives you balloon notifications for your Discord, with custom tray icons, custom sounds and it even shows PFPs on the balloons!!

It also includes:

- Status control from the tray icon (Online, Idle, Do Not Disturb, Invisible)
- **Notification Modes:** All Messages or Mentions Only (@me, @everyone, @here, replies)
- **Notification Styles:** Instant, Replace (Discord-style), and Queue (Discord Messenger-style)
- Custom sounds for every event — New Message, Mention, Mute/Unmute, Deafen/Undeafen, Call, and VC join/leave — with a volume slider
- Per-user sounds — assign specific sounds to individual friends
- Custom tray icons for each state: default, unread, in VC, muted, and deafened
- Clicking a notification opens the channel it came from *(Discord only)*
- Leave VC button in the tray context menu
- Translations via JSON files in the `langs/` folder
- Remember token, auto-login, and Start with Windows
- Auto-launches Discord on startup if it isn't already running
- On exit, asks whether to close Discord too *(with a "Don't ask again" option)*
- Compatible with both Discord and [Discord Messenger](https://github.com/DiscordMessenger/dm)
- Built-in event log and crash log
- Auto-Updater (experimental)
